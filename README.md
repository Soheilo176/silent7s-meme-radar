# Silent7s Meme Radar — Free MVP
Personal Telegram alert bot for early Solana tokens.

Important: official X API is pay-per-use and TikTok Research API requires eligibility/approval, so this free MVP uses pluggable public RSS/Atom trend feeds rather than pretending to have unrestricted X/TikTok access. Solana market data comes from DEX Screener.

Setup:
1. Copy .env.example to .env
2. Put your Telegram BotFather token in TELEGRAM_TOKEN
3. Keep CHAT_ID=588505226
4. pip install -r requirements.txt
5. python main.py

Commands: /start /status /scan

This is a screening tool, not investment advice.
